Waypoint

Record once, replay many: automation for legacy bank software that has no API.

The problem

Banks run hundreds of back-office systems. Many have no API, so the only way in is the screen.

Scripts

No test IDs, identical links, pages that change without the URL changing. They usually only handle the happy path.

A model, every time

Slow, costly and not repeatable. Improvising on a screen that moves money isn't acceptable.

And in a bank

Data must not leak. Some actions can't be undone. A person has to be able to step in.

The solution

1 · DISCOVER

Model learns once

An LLM works out the flow on the live app.

2 · COMPILE + APPROVE

A capability

Typed inputs, outputs and checks. A person approves it.

3 · REPLAY

No model

Reviewed steps and checks; no model calls on the default path.

4 · HAND OFF

A person steps in

Same live browser, then control comes back.

Recap

The model discovers once. A person approves the capability. Normal execution replays without a model and says exactly what happened. When it can't act safely, a person takes the live session.

It never acts on the absence of evidence.

Also built: stability and confidence, a capability catalog, assisted relocation and code generation. Tenant variants and desktop execution are designed, not built. Design and trade-offs: REPORT.md
